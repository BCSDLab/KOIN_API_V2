# Staging external secrets

This change is scoped to develop deployment. The production workflow is unchanged.
The artifact omits Firebase JSON and secret environment-placeholder leaves. The stage
host starts Spring Boot PropertiesLauncher with an external read-only resource and
configtree generated by its dedicated OpenBao Agent. No OpenBao token enters CI or
the application. Do not reintroduce the Firebase build-secret step.

## Deployment contract

- `backend-cd-develop.yml` runs on a push to develop. Merging this PR triggers staging deployment.
- Concurrency group `koin-stage-deploy` serializes uploads/deployments without cancelling a running deployment.
- The artifact is uploaded to `/usr/local/koin/api/KOIN_API_V2.jar`; the workflow invokes `/usr/local/koin/api/deploy.sh` explicitly. The old hidden path secrets no longer select the artifact or deploy command for this workflow.
- The installed root-owned entry point dispatches a systemd deployment worker. It takes an exclusive stage lock, freezes the upload, validates/sanitizes it, checks fresh OpenBao access, and retains the previous artifact/config.
- The 2GB host uses one JVM at a time on8081. Expect a short staging interruption; this is not zero-downtime blue/green deployment.
- Readiness, read-only shop endpoints and injection receipts must pass. A startup/verification failure restores the previous artifact/config and returns a nonzero result to CI. A systemd failure handler also recovers a pending deployment if its worker terminates unexpectedly.
- A successful app unit is enabled for boot. It fetches secrets again on each start. Earlier artifacts and protected recovery material are not automatically deleted.

The host implementation lives in [bcsdpdevops/host/secrets/deployment](https://github.com/BCSDLab/bcsdpdevops/tree/main/host/secrets/deployment).
The manifests/sanitizer/runtime here are a vendored snapshot of that repository.
Keep them synchronized through a reviewed PR. Runtime access, startup, ordinary
settings allowlist, certificate operations and rollback remain host concerns.
